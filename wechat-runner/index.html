OWNER MEETING · WINDOWS PILOT 0.1

两店微信首次试跑

由项目负责人在一台办公电脑上操作，先验证复兴香园店、新天地二店。

这是首次试跑版本，尚未在你的微信4.1.15.56上验证。
先检查群名、文字与图片粘贴并取消；通过后，“开始两店试发”才会启用。选择资料包和仅检查都不会点击发送。

当前验证“工作台已生成的资料包 → 微信选群 → 提交对应内容”。定时自动取数、18店无人值守尚未启用。

01 · 一次安装

先安装 Python 3.13，再安装试跑工具

  1. 打开 Python 官方 Windows 下载页，选择 Python 3.13 系列的 Windows installer (64-bit) 安装，保留 Tcl/Tk 和启动器选项。
  2. 下载本页工具，右键 ZIP 选择“全部解压缩”，放到固定文件夹。不要在压缩包内部运行。
  3. 双击 01_install.cmd，保持联网，看到“安装完成”后关闭窗口。
02 · 准备资料

生成两店试行资料包

打开 原工作台，用你的项目负责人账号登录：

日常推动 → 动作追踪与结果 → 生成2店试行资料包

下载资料 ZIP 即可，不要解压；不要选择18店资料包。

03 · 首次检查与试发

先“仅检查”，通过后再“开始两店试发”

  1. 保持电脑微信已登录，只打开一个用于试跑的主窗口，把窗口放大或最大化。
  2. 双击 02_start.cmd，选择刚下载的“两店试行资料包”。核对数据截止日期、完整群名和每店内容。
  3. 点击“仅检查（不点发送）”。程序会临时粘贴文字和图片并取消，不会点发送。期间暂时不要操作键鼠、切换窗口或锁屏；按 Esc 可停止。
  4. 检查通过后，由你点击“开始两店试发”，逐店提交对应话术和图片。明细分页会全部保留。
  5. 到两个微信群核对文字、图片和顺序。“已提交”表示界面提交完成，不等于网络已送达；状态不明会停止，不自动重发。
检查没通过时

保留检查报告，继续适配

如果读不到微信界面，可先退出微信，用 Win + Ctrl + Enter 打开讲述人，再重新打开微信；能读取后可关闭讲述人。仍失败时不要改选相似群。

点击程序里的“打开检查报告和发送记录文件夹”，将 latest-check.json 发回继续处理。报告不包含聊天记录、话术正文和图片内容。

本工具使用公开的Windows UI Automation与剪贴板接口；尚未进行真实Windows和微信端验证。已完成资料包路由、顺序、中断及防重复提交的自动检查。
